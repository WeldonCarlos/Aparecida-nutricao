# Aparecida Nutrição

Exercício de HTML e CSS que apresenta uma tabela de pacientes em um cenário de acompanhamento nutricional.

## O que o projeto apresenta

- Tabela de nome, peso, altura, gordura corporal e IMC.
- Estilos e arquivo de reset separados.
- Organização semântica com cabeçalho e conteúdo principal.

## Tecnologias

HTML · CSS

## Executar localmente

Clone o repositório e abra `index.html` no navegador. Para servir os arquivos localmente, use um servidor estático, como Live Server. Não há etapa de build.

## Estrutura

- `css/`
- `favicon.ico`
- `index.html`

## Estado atual

O repositório atual não contém JavaScript para cálculo de IMC; os valores são apresentados como conteúdo estático.
